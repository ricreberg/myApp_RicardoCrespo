## Objetivo

Comprender la estructura de un proyecto Ionic con Angular y conectar
los datos de TypeScript con la vista HTML mediante interpolación
y Property Binding.

## Trabajo realizado

- Comprobación de versiones de Node.js, Ionic CLI y Angular CLI.
- Análisis de dependencies y devDependencies en package.json.
- Arranque del servidor y explicación de Live Reload.
- Incorporación de foto1.jpg a src/assets.
- Creación del componente galeria con propiedades de tipo string.
- Interpolación del título y la descripción.
- Carga de la imagen mediante [src]="rutaImagenLocal".
- Validación del resultado en /galeria.

## Tecnologías

Ionic, Angular 22.0.1, TypeScript y SCSS.

## Ejecución local

Desde la carpeta del proyecto:

```bash
npm ci
ionic serve
```

Accede a http://localhost:8100/galeria.

## Compilación

```bash
npm run build
```

La aplicación compilada se genera en www.
